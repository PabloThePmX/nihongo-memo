# Functional Requirements

## Filters
* Filter which writing systems will be used.
* Filter which lines will be considered in Kana.
* Filter how many questions the user will need to answer, and how many lives.
* Filter kanji levels. (LATER) 

## Game Modes
* Determinate the quantity of questions, and if 3 or 1 lives will be available.
  * Or infinite lives.
* Endless mode, with 3 or 1 lives as well.
  * End button in case the user don't want to lose on purpose.
* Selecting options (4) or writing Rōmaji. (LATER)
* Questions should have more "similar" characters.
* Add game mode with time. (LATER)

## UI
* English, Portuguese, Italian, Spanish interfaces.
* Light and dark mode.
* Different fonts. (LATER)
* Display all the answers in the end.
* Show the score, and the % of correct answers.
* Mobile ready.

# Non Functional Requirements

* Caching the questions.
* Work offline.

* Keyboard navigation. (LATER)
* Color blind. (LATER)
* Font size. (LATER)
